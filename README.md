# 🐰 呱呱 Codex 桌宠合集 | Guagua Codex Pet Collection

> Pixel-art animated desktop pets for Codex Desktop · Codex Pet · AI Coding Companion

基于《洛克王国》页游经典角色“呱呱”制作的**非官方 Codex V2 像素桌宠合集**，包含原版呱呱、少林呱呱、富贵呱呱和逍遥呱呱四种形态。

四种桌宠均采用统一的 **8×11 spritesheet 动画布局**，可作为自定义 Codex Pet 安装到 Codex Desktop。每种形态均提供独立安装包、像素动画资源和动画预览。

An unofficial **pixel-art Codex desktop pet collection** based on Guagua from the *Rock Kingdom* web game.

The collection includes four animated Guagua forms — Original, Shaolin, Fugui, and Xiaoyao. Each custom Codex pet uses the same **8×11 spritesheet layout** and includes an independent installable package and animation previews.

## 📦 安装 / Installation

### 中文

1. 选择上方任意一种呱呱形态。
2. 进入对应目录。
3. 找到内层同名安装文件夹，例如：

```text
guagua-428/
└── guagua-428/
    ├── pet.json
    └── spritesheet.webp
```

4. 将**内层同名文件夹**复制到 Codex 的 `pets` 目录。
5. 打开 **Codex Desktop → Settings → Pets**。
6. 选择对应的呱呱桌宠。

安装包文件夹中仅包含：

```text
pet.json
spritesheet.webp
```

每种形态的完整介绍以及动画预览，请查看对应目录中的 README。

### English

1. Choose one of the Guagua forms above.
2. Open its directory.
3. Locate the inner pet package folder.
4. Copy that folder into the Codex `pets` directory.
5. Open **Codex Desktop → Settings → Pets**.
6. Select your Guagua pet.

Each installable package contains only:

```text
pet.json
spritesheet.webp
```

See the README inside each pet directory for additional details and animation previews.
